# Hearth Studio

Ранняя локальная сборка Hearth Studio для macOS. В одном приложении можно создавать независимые студии, назначать роли, запускать задачи, отвечать на вопросы из входящих и открывать результаты.

## Запуск

Нужен Node.js 24 или новее. Для живых задач установите и авторизуйте Codex CLI или Claude Code штатным способом.

```sh
npm ci
npm test
npm start
```

Команда `npm run package:mac` собирает локальное приложение для архитектуры текущего Mac в `dist/`. Данные студий сохраняются в каталоге приложения пользователя. Переменная `HEARTH_DATA_DIR` позволяет указать отдельную папку профиля.

## Первый цикл

1. Создайте студию и выберите отдельную рабочую папку.
2. В настройках проверьте подключение. Выберите модель и reasoning директора или оставьте значения подключения по умолчанию.
3. На обзоре создайте задачу и запустите её. Результат появится в карточке задачи. Если агент задаст вопрос, ответьте на него из входящих.
4. Добавьте роль в настройках студии. Мастерская автоматически разместит агента в подходящей комнате.

Codex App Server работает в ограниченном режиме чтения выбранной папки. Адаптер Claude Code обрабатывает текст поручения в режиме с отключёнными инструментами. Его протокол проверяют тесты с подставным CLI. Для живой проверки нужно доступное авторизованное подключение.

Предварительный импорт в настройках читает структуру прежней студии и показывает счётчики, объём артефактов, возможные пути и предупреждения. Этот экран предназначен для оценки переноса.
