# Hearth Studio

Локальное приложение для нескольких независимых студий. Директор предлагает план, создаёт команду после согласования, назначает задачи, передаёт результаты на ревью и выбирает следующий шаг. Работу видно на канбане, в итогах спринта и в мастерской.

## Запуск

Локальная сборка для macOS на Apple Silicon находится в `dist/0.2.1/`. Данные хранятся отдельно от исходников и проекта. Если открыт предыдущий экземпляр Hearth Studio, закрой его перед запуском новой сборки.

Для разработки нужен Node.js 24 или новее.

```sh
npm ci
npm test
npm start
```

`npm run package:mac` собирает локально подписанное приложение в `dist/<версия>/`. Для тестирования в отдельном профиле подходит переменная `HEARTH_DATA_DIR`.

## Первый спринт

1. Создай студию. Опиши цель, аудиторию и первый результат, выбери язык, подключение и рабочую папку. Папку можно создать в системном диалоге.
2. Нажми «Инициализировать студию». Проверь команду, задачи и критерии. «Подтвердить и запустить» создаёт роли и запускает спринт.
3. В «Работе» видны канбан, эпики, истории, спринты и встречи. Из карточки задачи открываются отчёт, ревью и файл результата.
4. Следующий план по умолчанию ждёт решения во «Входящих». Режим меняется в «Настройки → Автономность».

В «Настройки → Автономность» можно задать рабочие дни и часы. Время берётся с Mac. Новые задачи за пределами окна ждут, текущие завершаются. Приложение должно оставаться запущенным. Файлы и отчёты доступны в «Работа → Артефакты». «Удалить студию» находится в её настройках и удаляет записи из Hearth. Папка проекта сохраняется.

## Подключения и перенос

Codex использует временные сессии. Hearth хранит задачи, ответы и результаты. Для Claude Code нужен авторизованный CLI. Адаптер Claude проверен на подставном CLI. Передача задачи между Codex и Claude проверена на тестовых данных.

В настройках доступны экспорт шаблона, снимок с выбранными текстовыми артефактами, чтение прежней Hearth и перенос в отдельную папку. Снимок переносит связи задач, спринтов и встреч. Для выполнения связанных с Git задач после миграции потребуется сверка рабочей копии.
