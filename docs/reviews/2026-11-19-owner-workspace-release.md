## Сверка реализации

- **S1, S4.** На широком экране список и изменяемый по ширине инспектор видны вместе. В узком окне подробности занимают рабочую область. Поиск, фильтры, связи спринта, эпика и задачи, участники, результаты, обсуждения, расход, пагинация и история доступны из реальных данных. Новые переходы сохраняются в транзакции с изменением задачи. Сведения об известном инициаторе и использованной версии навыка записываются с момента появления этой возможности.
- **S2.** Портфель показывает цель, доступность папки, расписание, работу и обращения. Обзор учитывает локальную отметку просмотра конкретной студии. Прочитанный сбой, закрытое обращение и подтверждённая доставка имеют разные состояния.
- **S3, S5.** Первый план остаётся черновиком до решения. Доступны сравнение редакций, правка назначений, модели и усилия задачи, независимый проверяющий, выбор одиночной или пакетной приёмки. В режиме удержания Git работа поступает в ветку пакета. Целевая ветка обновляется после проверок, ревью и принятия конкретной версии. История решения остаётся доступной из входящих и задачи.
- **S6.** Профиль агента общий для карты, таблицы и карточки работы. Доступны сводки по эпикам и спринтам, позиции встречи, версии артефактов и знаний, поиск материалов, настройки приложения и студии. Архивирование обратимо. Отсоединение сохраняет файлы и требует проверки привязки для проектов с существующими результатами.
- **S7.** Повторные события расхода дедуплицируются; кэш не удваивает вход. При неизвестных или частичных данных интерфейс указывает покрытие. Экспорт сохраняет историческое решение и состав пакета с переназначением ID. Импорт снимка не даёт разрешения слить старую версию в новую папку.
- **S8.** Полный набор Node-тестов — **271 прошёл, 0 упало, 0 пропущено**. Сквозная проверка использует детерминированные CLI-имитаторы. Разработка не требует действующего аккаунта Claude.

## Сборка и повторение

Для проверки выполнить `npm test` и `npm run package:mac`. Бандл — `dist/0.4.0/Hearth Studio-darwin-arm64/Hearth Studio.app`. Проверка `codesign --verify --deep --strict` прошла, подпись локальная ad hoc. Включённая иконка побайтно совпадает с `assets/hearth.icns`. Содержимое 66 файлов приложения в архиве Electron сверено с рабочим деревом. SHA-256 `app.asar` — `cbc9c110c0c04f08579e84d5ab9b20f8d1367855d23fd4384a26ece596d83b0c`.

Скрипт `scripts/qa-owner-workspace.mjs` принимает `HEARTH_BUNDLE` (полный путь к исполняемому файлу в .app), `HEARTH_QA_LOCALE` и необязательные `HEARTH_QA_ZOOM=1` и `HEARTH_QA_REVEAL=1`. Он создаёт временные профили и выводит путь к снимкам. Провайдерные процессы направлены на тестовые бинарники. ## Границы подтверждения

Нативный выпускной прогон выполнен на macOS arm64. Для win32 и Linux проверен контракт системного показа файла и запасного действия с тестовыми оболочками. На момент этой проверки личная Windows VM была приостановлена, Linux-движок был выключен. Отдельного нативного результата с Проводником Windows и файловым менеджером Linux в этом отчёте нет. Проверены клавиатура и дерево доступности Electron. Полный сеанс с VoiceOver, пользовательский замер ориентира 30 секунд и запрос к живому аккаунту Claude остаются отдельными проверками. Переводы интерфейса подготовлены локально; основные команды и предупреждения прошли независимую вычитку. Полная редакторская вычитка носителями всех четырёх дополнительных языков не проводилась.
