## Как воспроизвести

1. Создать новый профиль без пользовательских настроек проекта.
2. Выполнить шаги 1–3 из руководства «Первый запуск».
3. Перейти к шагу 4 и попытаться настроить локальную конфигурацию только по тексту.

Ожидание: руководство указывает источник файла и объясняет обязательные поля.

Фактически: файл упомянут без пути и примера. На машине автора он уже существовал, поэтому прежняя проверка не обнаружила пробел.

## Условие повторной проверки

Принять T-10: безопасный пример конфигурации, место установки и ожидаемый вывод проверки. После этого повторить весь сценарий на новом профиле. Не продолжать текущий прогон с середины: это исказит время первого запуска.

Дополнительное наблюдение: описание ошибки импорта в шаге 3 помогло отличить ожидание ресурсов от ошибки проекта. Этот фрагмент стоит сохранить.
