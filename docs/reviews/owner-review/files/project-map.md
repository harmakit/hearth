# Карта проекта

Статус: на проверке в T-4.

| Папка | Что искать | Кто отвечает |
| --- | --- | --- |
| game/ | Сцены, логика и ресурсы продукта | Разработчики |
| game/test/ | Проверки игровых систем | Разработчики и QA |
| docs/ | Намерение владельца и требования к качеству | Владелец и директор |
| kb/ | Рабочие знания и проверенные решения | Библиотекарь |
| tools/qa/ | Запуск, smoke и тестовый harness | Инженер инструментов |

Перед изменением прочитайте локальные правила папки. Защищённые файлы меняет только владелец. Если обнаружили необходимость изменить инструмент, оформите отдельную задачу с шагами воспроизведения.

Пример: исправление текста игрового интерфейса начинается в game/. Изменение процедуры QA начинается с задачи инженеру инструментов.

Замечание ревью: добавить пример изменения общего ресурса и указать, какие потребители следует проверить.
