# Первый запуск

Цель: за полчаса получить рабочий проект на чистой машине. Этот черновик проверяется в T-9. Известный пробел с локальной конфигурацией исправляется в T-10.

## 1. Проверьте инструменты

Убедитесь, что установлены Git, Python 3 и Godot 4. Версия движка должна совпадать с указанной в проекте. Ожидаемый результат: каждый инструмент печатает свою версию без ошибки.

## 2. Откройте проект

Клонируйте репозиторий в отдельную папку и откройте project.godot. Дождитесь окончания первого импорта ресурсов. Не прерывайте импорт: первый запуск занимает больше времени, чем последующие.

## 3. Выполните проверку разбора

Из корня проекта запустите tools/qa/parse-gate.sh. Ожидаемый результат: код завершения 0. Если проверка сообщает об отсутствующем классе, сначала проверьте, завершён ли импорт.

## 4. Запустите локальный сценарий

Настройте локальную конфигурацию и откройте стартовую сцену. Ожидаемый результат: окно проекта открывается без ошибок.

**Замечание QA:** источник локальной конфигурации здесь не указан. Сценарий остановлен на этом шаге; см. отчёт первого прогона.

## 5. Подготовьте первый вклад

Выберите небольшую задачу из очереди, прочитайте критерии готовности и уточните ожидаемый результат. После изменения выполните относящиеся к нему проверки и приложите результат к задаче.
