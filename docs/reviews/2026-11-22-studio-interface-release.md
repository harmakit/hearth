Полный набор Node-тестов: **287 прошли, 0 ошибок**. Независимое ревью обнаружило три проблемы высокой серьёзности. Архивированное обращение могло принять устаревший ответ, ввод мог перезаписать признак незавершённого создания, а отложенное возобновление могло закрыть другой диалог. Исправления сверены повторным ревью и целевыми тестами.

Тестированная копия — `dist/0.4.0/Hearth Studio-darwin-arm64/Hearth Studio.app` в отдельном рабочем дереве. Проверка локальной подписи `codesign --verify --deep --strict` прошла. Файл иконки совпал с `assets/hearth.icns`. SHA‑256 `app.asar` — `6ab7ef596fcefab479518f3605673c7ff416d4ac0a2183629c11135e670cc161`.

```sh
node --test test/*.test.mjs
npm run package:mac
bundle="$PWD/dist/0.4.0/Hearth Studio-darwin-arm64/Hearth Studio.app"
codesign --verify --deep --strict "$bundle"
HEARTH_BUNDLE="$bundle/Contents/MacOS/Hearth Studio" \
  HEARTH_QA_TODAY=1 HEARTH_QA_ONBOARDING_FIX=1 HEARTH_QA_RESIZE=1 \
  HEARTH_QA_ZOOM=1 HEARTH_QA_REVEAL=1 HEARTH_QA_LOCALE=ru \
  node scripts/qa-owner-workspace.mjs
```
