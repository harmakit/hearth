# Что стоит перенести из прежней Hearth

Сравнение сделано по исходникам и документации. Базовая точка новой версии — коммит `8721edd`, до работ над коучем и обучением. Прежняя студия находилась в отдельном репозитории. Код и рабочие данные этой студии читались без записей.

Номера позволяют выбрать механики для переноса. «Частично» означает, что часть сценария уже выполняется в новом приложении. Оценка «Отсутствует» относится к сравнению с указанной версией. Набор механизмов коуча описан в отдельном [плане обучения](superpowers/plans/2026-11-18-agent-coach.md).

В старой схеме директор назначал `train` по конкретному пробелу. Обязательная подготовка каждого новичка — новое правило, согласованное для Hearth Studio. [Старое решение по найму и обучению](/Users/harmakit/projects/hearth/docs/superpowers/specs/2026-10-14-studio-process-v2-design.md:67)
