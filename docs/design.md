# Hearth Studio для macOS

Hearth Studio — локальное настольное приложение для нескольких независимых студий. Первая сборка воспроизводит проверенный в прототипе путь от рабочей папки до задачи, решения владельца и отчёта. Каждая студия хранит свой язык отчётов, бриф, роли и политику выбора модели.

## Устройство

- Electron открывает локальные экраны «Обзор», «Входящие», «Мастерская» и «Настройки». Изолированный preload передаёт ограниченный набор команд. Сетевой сервер для интерфейса не требуется.
- Локальная SQLite хранит студии, состав, задачи, решения и результаты. Закрытие окна оставляет работу в приложении. Прерванная попытка видна после перезапуска и требует явного повторного запуска.
- Адаптеры Codex App Server и локального Claude Code реализуют одинаковый контракт запуска. Доступность, каталог моделей, аккаунт и усилие зависят от подключения. Claude проверяется с подставным CLI, а живой запуск Codex проверяется только на выделенной тестовой папке.
- На первом этапе агент готовит текстовый результат в рамках доступной ему рабочей папки. Приложение сохраняет результат и отдельный вопрос, если агенту требуется решение. Ответ возвращает задачу в очередь. Папка проекта выбирается отдельно от хранилища Hearth.
- Hearth автоматически группирует роли по зонам. Обстановка комнаты определяется её назначением, рабочее место — ролью. Клик по агенту показывает связанную задачу. Первой версии достаточно предсказуемой группировки по ролям, к которой позже можно подключить рекомендации директора.
- Источник старой игровой студии используется только для чтения. Предварительный импорт показывает набор данных, пути, состояние рабочих деревьев и объём артефактов. Реальный перенос и запуск на копии требуют отдельной проверки путей и состава данных.

## Критерии первой сборки

1. В отдельном Mac-приложении создаются и независимо отображаются две студии.
2. Задача из первого проекта доходит до результата на Codex. Вопрос отображается во входящих, ответ сохраняется и продолжает задачу.
3. Настройки позволяют выбрать Codex или Claude Code, модель и усилие директора, а для роли — наследование, фиксированный выбор или выбор из списка студии.
4. При смене состава карта комнаты меняется автоматически. По роли видно текущую работу.
5. Ошибка одного подключения остаётся у соответствующей задачи. Уже записанное состояние доступно после перезапуска.
6. Исходный репозиторий, игра и рабочие деревья остаются на месте. Из старой студии можно получить только предварительный отчёт об импорте.
