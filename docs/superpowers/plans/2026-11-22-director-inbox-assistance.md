# Входящие через директора · план реализации

Спецификация согласована. [Входящие через директора](../specs/2026-11-22-director-inbox-assistance.md).

- [x] Создать единый редактор ответа. Варианты заполняют текст, «Свой вариант» восстанавливает черновик, «Отправить» сохраняет текущий текст с ID и версией входящего. Переиспользовать редактор для плана, вопроса, приёмки и сверки.
- [x] Поставить ответ в сохраняемую очередь директора. При повторе сверять ID операции и содержимое запроса. Прерванное действие требует новой отправки.
- [x] Передавать директору актуальный объект и допустимые действия. До применения сверить версии, согласие на приёмку и завершение прежнего процесса. Использовать существующие команды студии. После применения показывать фактический исход и связанный объект.
- [x] Проверить, что выбор варианта не создаёт запрос, «Отправить» передаёт отредактированный текст, объяснение оставляет входящее открытым, а повтор операции и устаревшая версия не меняют данные. Пройти план, вопрос, ошибку, сверку и приёмку со слиянием на сборке macOS ARM64 в отдельном профиле с тестовым провайдером.
