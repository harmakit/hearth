# Реестр версий навыков

- Уже утверждённый навык остаётся неизменным: публичный репозиторий, путь SKILL.md, коммит, содержимое и лицензия. Проверка обновлений обращается только к сохранённому публичному репозиторию и пути, не ищет замену по названию.
- Проверять активные версии при открытии студии/старте приложения, с суточным кэшем, общим ограничением запросов GitHub и повтором после указанного времени. Проверка не блокирует работу. Отображать отдельно недоступность, неизменность содержимого и доступную новую версию.
- В библиотеке показывать текущий коммит, новый коммит, лицензию и содержание. Обновление не применяется без явного решения владельца. Новая версия — отдельная запись, старая остаётся для истории/экспорта.
- Применение записывается как одобрение владельца. Роли, использующие старую версию, переключаются только после завершения активных попыток. Новые запускаются после переключения. История попыток и материалов сохраняет исходные ID.
- Снимок/перенос проверяет цепочку явных одобрений от проверенного коучем навыка и связь с ролями. Нельзя заменить одобренный материал непривязанной записью.
- Проверки: неизменный и обновлённый файл, изменение лицензии, исчезновение/офлайн, лимит запросов, отказ, применение при активном запуске, перенос истории.
