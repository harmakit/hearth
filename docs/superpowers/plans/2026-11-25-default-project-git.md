# Git по умолчанию для студий

## Поведение

- Новая папка и существующая папка без Git получают пустой начальный коммит и отдельную ветку доставки. Файлы проекта не добавляются в индекс.
- В существующем самостоятельном репозитории Hearth предлагает управляемую ветку на текущем коммите или явный выбор существующей локальной ветки. HEAD, индекс и рабочие изменения не переключаются и не перезаписываются. Для репозитория без коммитов начальный коммит создаётся без изменения существующего индекса.
- Папка внутри чужого репозитория не становится вложенным репозиторием. Мастер предлагает выбрать самостоятельный корень. При открытии прежней студии в такой папке данные остаются доступными на паузе, но сообщается, почему Git не подключён.
- При первом открытии переносимой студии без настроенного Git и переносе прежнего формата применяется тот же порядок. Явное отключение Git сохраняется и не отменяется при повторном открытии.
- В обзоре настроек — состояние локального репозитория и короткая ветка; полный ref и проверки остаются в настройках Git.

## Проверка

- [x] Создание новой и существующей папок, сохранение непроиндексированных файлов.
- [x] Существующий Git с staged и unstaged изменениями, отдельная ветка по умолчанию и явный выбор.
- [x] Несамостоятельная папка и репозиторий без первого коммита.
- [x] Перенос прежней студии и открытие переносимой папки, в том числе явное отключение.
- [x] Нативный мастер и отображение статуса; полная сборка и регрессии.

В Existing Repo мастер показал доступную ветку `delivery-choice`, отключил выбор уже открытой `main`. Настройки показали короткую ветку и полный ref.
