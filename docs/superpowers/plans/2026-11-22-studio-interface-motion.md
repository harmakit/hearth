# Hearth Studio · план реализации движения

> Исполнение по шагам через superpowers:executing-plans. Отметки отражают проверенный результат.

**Цель.** Дать короткий отклик на нажатия и переходы между контекстами, выделить результат команды на месте.

**Архитектура.** Стили определяют длительность и оформление состояний, нативный диалог сохраняет свой жизненный цикл. Renderer сохраняет узел результата на «Сегодня» во время перерисовки списка и сверяет подтверждённые результаты по ключу перед одноразовой подсветкой.

**Стек.** Electron, CSS, Web Animations API, сценарий проверки через DevTools Protocol.

**Спецификация.** [Движение интерфейса](../specs/2026-11-22-studio-interface-motion.md).

## Приёмочные случаи

- Escape сразу отдаёт фокус исходной строке или кнопке, даже при незавершённом переходе.
- Смена данных открытого инспектора сохраняет его положение и исключает повторное появление панели.
- Завершение команды показывает подтверждённый результат, повтор снимка сохраняет узел и выполняющуюся анимацию.
- Повторный вход в «Сегодня» сохраняет предыдущий результат в спокойном состоянии.
- Изменение системной настройки останавливает текущий эффект и исключает запуск последующих.
