# Приёмка Hearth Studio 0.3.0

Проверки относятся к отдельной ветке `legacy-mechanics`. Исходная Hearth и игра не участвовали ни в запуске, ни в переносе.

| Пункты | Свидетельства |
|---|---|
| 01–07 | Тесты диспетчера и рабочего цикла. WIP 2, отдельная остановка, замена аренды после сверки, повтор операции после записи файла, ночное расписание и смена часового пояса. Отдельный живой запрос Codex завершился в подтверждённой временной сессии. |
| 08–15 | Тесты планирования, встреч и ретро. Следующий спринт использует тот же ID карточки, эпика и истории. Покрыты перенос, приоритеты, порог груминга, техдолг по баллам и числу карточек, сохранение оценки директором. |
| 16–21 | Настоящие тестовые репозитории. Отдельные рабочие деревья, проверка содержимого и кандидат слияния, привязка ревью, защита занятой ветки, откат доступности после сбоя, доказательства и уборка. |
| 22–24 | Тестовый профиль запускает команды сборки, playtest и проверки ассетов. Результаты и логи можно открыть из карточки. Игровые команды штатного проекта настраиваются на отдельной копии игры. |
| 25–32 | Тесты бесед, вопросов, уведомлений, расхода и переноса. Записка использует свободный слот, ожидая решения по предложенному приоритету. Фикстура импорта сохраняет `owner_language`. |
| 33–39 | Тесты обучения, библиотеки, состава и встреч. Утверждение проверенного пакета, версии, откат, передача работы и точечный учебный допуск. |

## Команды

- `npm test` — 230 тестов прошли в последнем полном прогоне.
- `npm run package:mac` и `codesign --verify --deep --strict` — локальная сборка Apple Silicon и проверенная подпись. Версия пакета 0.3.0.
- Живой запрос отправлен через адаптер Codex в пустой тестовой папке. Результат `HEARTH_QA_OK`, постоянный идентификатор отсутствовал. Закрытие временного потока и отсутствие сохранённых сессий покрывают протокольные проверки.
- Claude Code проверен на подставном CLI. Проверка запроса к живой модели Claude требует доступного аккаунта.

## Границы проверок

Сценарии с файлами, медиа и Git запускались на фикстурах. Тесты проектного профиля покрывают интерфейс проверок и раздельную доставку доказательств. Godot, GdUnit, Blender и аудиопроцессы конкретной игры в этот прогон не входили.
